# Life & Death Talks

A personal blog page about grief, built as plain HTML for the Phase 3 HTML Skeleton activity. It features my Phase 1 post, "How Could There Be Life When There Is Death? Lessons from Grief."

## About this project

This project is built for Phase 3 at Caraga State University, College of Information and Computing Sciences, using my Phase 1 sketch and blog content.

## What I built

I built a valid HTML5 page with a doctype, a lang attribute, meta charset, meta viewport, and a title that describes the page. The layout is based on my sketch and uses header, nav, main, article, section, aside, and footer. The menu is a list of links that jump to each section of the page. My full blog post is on the page, with an h2 for the post title and h3 headings for each part. I also added a candle photo with alt text, placed in a figure with a figcaption that links to the photographer's credit. The comments in my HTML file explain what I learned about each tag.

The page has no CSS, no style attributes, and no outdated tags, so it looks plain on purpose. It passes the W3C HTML validator with no errors or warnings.

## Project files

The index.html file is the main page. The images folder holds the photos used in the post. The screenshots folder has screenshots of the page running in the browser and the validator result.

## How to view the page

Download or clone this repository, then open the index.html file in a web browser.
